# Release notes

## v1.2.0

### Breaking changes

- Python 3.8, 3.9 and 3.10 are no longer supported, and `djc-ext-pydantic` now requires Python 3.11 or newer. On an older Python, pip keeps installing v1.1.0.

### Feat

- Python 3.14 is now supported and tested.
